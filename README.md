# Netflix Data Analysis Project

## Objective
The objective of this project is to analyze Netflix content data and identify trends related to movies, TV shows, ratings, countries, and release years.

---

## Tools & Libraries Used
- Python
- Pandas
- Matplotlib

---

## Dataset
Dataset used: Netflix Titles Dataset

Main columns analyzed:
- type
- release_year
- rating
- country
- duration

---

## Data Cleaning
- Removed missing values using `dropna()`
- Converted movie duration from string to integer format

---

## Visualizations Created
1. Movies vs TV Shows Bar Chart
2. Content Ratings Pie Chart
3. Movie Duration Histogram
4. Release Year Scatter Plot
5. Top 10 Countries by Number of Shows
6. Movies vs TV Shows Trend Comparison

---

## Key Insights
- Movies dominate Netflix content compared to TV Shows.
- Most Netflix content is rated TV-MA and TV-14.
- Content production increased significantly after 2015.
- USA contributes the highest number of shows on Netflix.
- Most movies have duration between 80–120 minutes.
